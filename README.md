# Vigil

Ходибельный 3D-мир от первого лица: ночь, ливень, густой туман, бетонный пост
в тропическом лесу и одна зелёная лампа над дверью.

Мир 03 витрины [find-the-end.fun](https://find-the-end.fun) - небольших
браузерных миров, в каждом из которых спрятан свой конец.

## Стек

Three.js + Vite + TypeScript. Постпроцессинг - pmndrs/postprocessing.
Контроллер от первого лица, процедурные поверхности и предметы - общее ядро
миров [world-core](https://github.com/HippocampusEvolve/world-core).

Вся геометрия, поверхности и звук собираются кодом: ни одного файла моделей,
текстур или сэмплов.

## Запуск

```bash
npm install
npm run dev        # локальный сервер разработки
npm run build      # сборка в dist/
npm run preview    # посмотреть собранное
npm test           # проверки на Node
npm run typecheck  # типы
```

## Что где

| | |
|---|---|
| `src/world/` | геометрия мира и раскладка: все координаты в `layout.ts` |
| `src/layer/` | необязательный слой данных: без него мир собирается и работает |
| `src/` | оболочка входа, появление, игрок, атмосфера, звук |
| `test/` | проверки на Node |
